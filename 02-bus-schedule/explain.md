# EXPLAIN плана выполнения запроса

## Индексы

Для запроса электронного табло используются следующие индексы:

1. route_stops(stop_id)

Позволяет быстро найти маршруты, проходящие через выбранную остановку.

2. trips(departure_time)

Помогает фильтровать будущие рейсы и сортировать по времени отправления.

3. trips(route_id)

Ускоряет JOIN с таблицей routes.

---

## Ожидаемый план выполнения

Проверяем:

EXPLAIN ANALYZE
SELECT ...

Ожидаем увидеть:

- Index Scan по route_stops для поиска остановки;
- Index Scan или Bitmap Index Scan по trips;
- Nested Loop или Hash Join для соединения таблиц;
- сортировку по departure_time.

---

## Возможные улучшения

При большом количестве рейсов можно создать составной индекс:

CREATE INDEX idx_trips_time_route
ON trips(route_id, departure_time);

Он поможет при выборке конкретного маршрута по времени.
