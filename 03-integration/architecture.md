# Интеграция Bitrix24, Moodle и личного кабинета студента

## 1. Источник истины (System of Record)

### Bitrix24

Bitrix24 является главным источником данных о пользователе как о клиенте/абитуриенте:

- ФИО;
- контакты;
- статус абитуриента;
- статус "студент";
- учебная группа;
- изменения персональных данных.

### Moodle

Moodle отвечает за учебный процесс:

- курсы;
- задания;
- оценки;
- материалы;
- посещение занятий.

### Личный кабинет студента

Личный кабинет является пользовательским интерфейсом для студента:

- профиль;
- отображение учебной информации;
- доступ к сервисам.

Учебные данные не редактируются напрямую в личном кабинете, а приходят из систем-источников.

## 2. Передаваемые данные

| Откуда | Куда | Данные |
|---|---|---|
| Bitrix24 | Moodle | создание пользователя, ФИО, email, учебная группа, идентификатор студента |
| Bitrix24 | Личный кабинет | профиль студента, статус, группа |
| Moodle | Личный кабинет | курсы, оценки, задания, расписание |
| Личный кабинет | Moodle | запросы на получение учебной информации |

## 3. Способ интеграции

Для обмена данными используется REST API через отдельный интеграционный сервис.

Интеграционный сервис отвечает за:
- преобразование форматов данных;
- повторную отправку при ошибках;
- журналирование операций;
- контроль дублей.

Прямые связи Bitrix24 → Moodle → Личный кабинет не используются, чтобы уменьшить связанность систем.
